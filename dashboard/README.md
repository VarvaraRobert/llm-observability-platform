# Dashboard

React + TypeScript single-page app (Vite) for the LLM Observability Platform.
Prompts for an API key, lists traces with filters and pagination, and renders
each trace as a span tree with per-span and per-trace cost and latency.

## Scripts

- `npm run dev` — start the Vite dev server
- `npm run build` — type-check and build for production
- `npm test` — run the test suite (Vitest + React Testing Library + fast-check)

This is a placeholder scaffold; views and the span-tree reconstruction are
implemented in later tasks.
